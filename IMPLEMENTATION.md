# VOLO - Система управления волонтерскими мероприятиями

## Обзор реализованного функционала

### Для Организаций

#### 1. **Создание ивентов**
- Красивая многошаговая форма создания мероприятия (6 шагов)
- Поля: тип ивента, обложка, название, описание, дата/время, локация, количество волонтеров, обязанности, бенефиты
- Автоматическое сохранение в базу данных PostgreSQL
- Привязка ивента к организации через `organizer_id`

#### 2. **Управление заявками**
- Просмотр всех своих ивентов на вкладке "История" (OrganizerEventsPage)
- Клик на ивент → просмотр всех заявок волонтеров (OrganizerEventApplicationsPage)
- Для каждой заявки видно:
  - Имя волонтера (или email)
  - Аватар
  - Текущий статус (На рассмотрении / Одобрено / Отклонено / Завершено)
- Кнопки "Принять" и "Отклонить" для заявок со статусом "На рассмотрении"

#### 3. **Уведомления по email**
- При изменении статуса заявки волонтеру автоматически отправляется email
- Красиво оформленные письма с цветовой индикацией:
  - 🟢 Зеленый - заявка одобрена
  - 🔴 Красный - заявка отклонена
  - 🔵 Синий - другие статусы

### Для Волонтеров

#### 1. **Просмотр ивентов**
- Главная страница с каталогом всех активных мероприятий
- Фильтры по категориям (Эко, Спорт, Культура, Социальные)
- Детальная страница каждого ивента

#### 2. **Подача заявок**
- Кнопка "Подать заявку" на странице ивента
- Автоматическое создание заявки со статусом "pending"
- Защита от повторных заявок на один ивент

#### 3. **Отслеживание заявок**
- Страница "Мои заявки" (MyApplicationsPage)
- Две вкладки: "Активные" и "Архивные"
- Для каждой заявки отображается:
  - Название ивента
  - Организатор
  - Дата и локация
  - **Статус с цветовой индикацией**:
    - 🟠 Оранжевый - "На рассмотрении"
    - 🟢 Зеленый - "Принята"
    - 🔴 Красный - "Отклонена"
    - ⚪ Серый - "Завершена"
  - Анимированный индикатор статуса с пульсацией

#### 4. **Уведомления**
- Email-уведомления при изменении статуса заявки
- Страница уведомлений в приложении (NotificationsPage)
- Фильтры: Все / Новые / Прочитанные

## Технический стек

### Backend (Python/FastAPI)
- **База данных**: PostgreSQL
- **ORM**: SQLAlchemy
- **Аутентификация**: JWT токены
- **Email**: FastMail (Gmail SMTP)

### Frontend (Flutter/Dart)
- **UI**: Material Design + Google Fonts (Poppins)
- **Иконки**: SVG через flutter_svg
- **HTTP**: http package
- **Локальное хранилище**: shared_preferences

## API Endpoints

### События (Events)
```
POST   /events/                          - Создать ивент (организация)
GET    /events/                          - Получить все активные ивенты
GET    /events/my-events                 - Получить ивенты организации
GET    /events/{event_id}/applications   - Получить заявки на ивент (организация)
POST   /events/{event_id}/apply          - Подать заявку (волонтер)
GET    /events/my-applications           - Получить свои заявки (волонтер)
PUT    /events/applications/{id}/status  - Обновить статус заявки (организация)
```

### Модели данных

#### Event
- `id`, `title`, `description`, `category`
- `organizer` (название), `organizer_id` (FK к User)
- `date_text`, `full_date`, `location`, `hours`
- `image_url`, `is_active`, `created_at`

#### Application
- `id`, `user_id`, `event_id`
- `status` (pending / approved / rejected / completed)
- `created_at`
- Relationships: `user`, `event`

## Workflow

### Создание и управление ивентом

1. **Организация создает ивент**:
   - Заполняет форму в 6 шагов
   - Нажимает "Опубликовать"
   - Ивент сохраняется в БД с `organizer_id`

2. **Волонтеры видят ивент**:
   - На главной странице
   - В поиске и фильтрах

3. **Волонтер подает заявку**:
   - Нажимает "Подать заявку"
   - Создается Application со статусом "pending"

4. **Организация управляет заявками**:
   - Переходит в "История" → выбирает ивент
   - Видит список всех заявок
   - Нажимает "Принять" или "Отклонить"
   - Статус обновляется в БД
   - Волонтеру отправляется email

5. **Волонтер получает уведомление**:
   - Email на почту
   - Обновление статуса в "Мои заявки"
   - Цвет индикатора меняется
