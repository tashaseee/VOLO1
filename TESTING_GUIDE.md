# Инструкция по тестированию VOLO

## Быстрый старт

### 1. Создание тестовых аккаунтов

#### Организация
```
Email: org@test.com
Password: Test1234
Role: organization
```

#### Волонтер
```
Email: volunteer@test.com
Password: Test1234
Role: volunteer
```

### 2. Тестовый сценарий

#### Шаг 1: Регистрация организации
1. Запустите приложение
2. Выберите "Регистрация"
3. Выберите роль "Организация"
4. Заполните:
   - Email: `org@test.com`
   - Пароль: `Test1234`
   - Название организации: `Test Org`
   - БИН: `123456789012`
5. Подтвердите email (код придет на почту или в консоль backend)
6. Дождитесь одобрения администратором

#### Шаг 2: Одобрение организации (админ)
```bash
cd backend
source venv/bin/activate
python approve_org.py
```
Или через админ-панель в приложении (если есть админ-аккаунт)

#### Шаг 3: Создание ивента (организация)
1. Войдите как организация
2. Нажмите "+" в нижней навигации
3. Заполните форму:
   - **Шаг 1**: Выберите тип (например, "Экология и природа")
   - **Шаг 2**: Загрузите обложку (или пропустите)
   - **Шаг 3**: 
     - Название: "Посадка деревьев"
     - Описание: "Озеленение парка"
   - **Шаг 4**:
     - Дата: выберите будущую дату
     - Время: выберите время
     - Город: "Алматы"
     - Адрес: "Парк Горького"
   - **Шаг 5**:
     - Количество волонтеров: 10
     - Обязанности: выберите из списка
   - **Шаг 6**: Бенефиты (опционально)
4. Нажмите "Опубликовать"

#### Шаг 4: Регистрация волонтера
1. Выйдите из аккаунта организации
2. Зарегистрируйте волонтера:
   - Email: `volunteer@test.com`
   - Пароль: `Test1234`
   - Роль: "Волонтер"
3. Подтвердите email

#### Шаг 5: Подача заявки (волонтер)
1. Войдите как волонтер
2. На главной странице найдите созданный ивент
3. Нажмите на карточку ивента
4. Нажмите "Подать заявку"
5. Перейдите в "Мои заявки" (4-я иконка снизу)
6. Проверьте статус: должно быть "На рассмотрении" (🟠)

#### Шаг 6: Управление заявками (организация)
1. Выйдите и войдите как организация
2. Перейдите на вкладку "История" (3-я иконка снизу)
3. Нажмите на созданный ивент
4. Увидите список заявок с данными волонтера
5. Нажмите "Принять" (зеленая кнопка)
6. Проверьте email волонтера - должно прийти уведомление

#### Шаг 7: Проверка уведомления (волонтер)
1. Войдите как волонтер
2. Проверьте email - должно быть письмо "Заявка ОДОБРЕНА! 🎉"
3. Перейдите в "Мои заявки"
4. Статус должен измениться на "Принята" (🟢)

## Тестирование API напрямую

### Создание ивента
```bash
curl -X POST http://127.0.0.1:8000/events/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "title": "Test Event",
    "description": "Test Description",
    "category": "Экология и природа",
    "location": "Алматы",
    "hours": 5,
    "date_text": "25 Jan",
    "full_date": "2026-01-25T10:00:00"
  }'
```

### Получение заявок на ивент
```bash
curl http://127.0.0.1:8000/events/1/applications \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Обновление статуса заявки
```bash
curl -X PUT http://127.0.0.1:8000/events/applications/1/status \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"status": "approved"}'
```

## Возможные проблемы

### Backend не запускается
```bash
cd backend
source venv/bin/activate
pip install -r requirements.txt
```

### База данных не работает
```bash
# Проверьте PostgreSQL
psql -U postgres -d volo

# Пересоздайте таблицы
python reset_db.py
```

### Flutter не компилируется
```bash
cd volo
flutter clean
flutter pub get
flutter run
```

### Email не отправляются
- Проверьте интернет-соединение
- Проверьте настройки в `.env`
- Посмотрите логи в консоли backend
- Временно можно закомментировать отправку и смотреть коды в консоли
