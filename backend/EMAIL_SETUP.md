# Настройка почты VOLO (Gmail)

Коды регистрации, сброса пароля и уведомления уходят через **Gmail SMTP**.  
Нужен **пароль приложения** — не обычный пароль от входа в Google.

## Почему раньше работало, а сейчас нет

1. В `.env` могли пропасть строки `MAIL_USERNAME` / `MAIL_PASSWORD`.
2. Google **отзывает** старые пароли приложений (смена пароля, отключение 2FA, «Выйти везде»).
3. Ошибка `535 5.7.8 Username and Password not accepted` = неверный или устаревший пароль приложения.

## Шаг 1. Аккаунт Google

Используй тот же Gmail, с которого должны уходить письма (например `volo.2025.kz@gmail.com`).

1. Войди: https://myaccount.google.com/
2. **Безопасность** → включи **Двухэтапную аутентификацию** (обязательно для паролей приложений).

## Шаг 2. Пароль приложения

1. Открой: https://myaccount.google.com/apppasswords  
   (если ссылки нет — в поиске настроек Google введи «Пароли приложений»).
2. **Выберите приложение** → «Почта» (или «Другое»).
3. **Выберите устройство** → «Другое» → название `VOLO`.
4. Нажми **Создать**.
5. Google покажет **16 символов**, например: `abcd efgh ijkl mnop`  
   В `.env` пиши **без пробелов**: `abcdefghijklmnop`

## Шаг 3. Файл `backend/.env`

```env
MAIL_USERNAME=volo.2025.kz@gmail.com
MAIL_PASSWORD=abcdefghijklmnop
MAIL_FROM=volo.2025.kz@gmail.com
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
```

- `MAIL_USERNAME` и `MAIL_FROM` — **один и тот же** адрес Gmail.
- `MAIL_PASSWORD` — только пароль приложения (16 символов), не пароль от аккаунта.

## Шаг 4. Перезапуск сервера

```bash
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8080
```

Зарегистрируйся снова — в консоли должно быть: `✅ Email «верификация» отправлен на ...`  
Письмо проверь во **Входящих** и в **Спам**.

## Если снова 535

- Создай **новый** пароль приложения и замени `MAIL_PASSWORD`.
- Убедись, что 2FA включена.
- Для корпоративных Google Workspace может быть запрещён SMTP — тогда нужен другой почтовый сервис.

## Режим «только консоль» (без почты)

Не заполняй `MAIL_USERNAME` / `MAIL_PASSWORD`, либо добавь:

```env
MAIL_FORCE_CONSOLE=true
```

Код будет в терминале, где запущен uvicorn.
